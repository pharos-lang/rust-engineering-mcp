## Diferencias y limitaciones encontradas

1. HEAD/CI han avanzado respecto al release; se registran ambos sin cambiar historia.
2. CHANGELOG conserva «No se ha publicado ninguna release binaria»; SECURITY
   conserva «No existe todavía una versión binaria soportada» y una introducción
   de límites M0; compatibilidad conserva una fila que mezcla CI y macOS x86_64.
   Son contradicciones documentales visibles con ADR-048 y evidencia live, registradas
   en [trazabilidad](traceability-m2-m8.md). Esta fase no repara documentos fuera del
   scope autorizado. No se identificó aquí un defecto de ejecución que invalide M1.
3. El experimento M1-16 fue acotado/saturado: no demostró equivalencia, efecto causal,
   valor de producto ni calidad general. Ningún hito recibe esos claims por herencia.
4. El código/ADRs declaran fuentes readonly y ninguna transacción de escritura de
   proyectos. Esa es una precondición de M2, no una implementación parcial ya existente.

arquitectura/tools/security/compatibility/CI/publication/tablero, las matrices
