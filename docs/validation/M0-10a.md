# M0-10a — Ephemeral bounded ArtifactStore

ADR-028 records the explicit refinement of ADR-014: memory-only in M0. No disk
permission, durable artifact or MCP Resource integration claim. Eight-crate
workspace on macOS26.6.2 ARM64 with Rust/Cargo1.98.1.

## Behavior

Internal ArtifactInput/ArtifactStore ports, opaque OS-random128-bit IDs, owner-bound
borrowed retrieval, SHA256 of stored bytes, conservative truncation, global/owner
bytes and counts, monotonic TTL and cleanup/revocation. Maximum draft reservation
precedes input consumption; errors never publish. Entropy/clock/arithmetic failures
fail closed. Clock regression clears and permanently poisons the store.

Literal redaction masks every matched byte, including overlapping patterns across
4096-byte chunks. Pending flags and original suffix protect truncated/potential
secret prefixes. At most8 patterns of1..128 bytes; byte input cap1MiB, output256KiB,
global16MiB, owner1MiB,256/64 artifacts and TTL1..86400s. Host can lower limits.

The source must be trusted/nonblocking. Quotas bound retained content, not process
RSS; secret-pattern storage and allocator overhead are separate. The producer's
wall/cancellation/kill-tree remain gateway responsibilities. M1 must resolve a live
ProjectRef, connect logs/diffs to this port and expose authenticated Resource reads.
M0's public tool list remains unchanged. Reads check expiry on operation; a borrowed
view cannot be revoked asynchronously while it is held by the trusted integrator.
