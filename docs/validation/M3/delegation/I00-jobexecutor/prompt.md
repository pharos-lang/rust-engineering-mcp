## Interfaces to fix in this package (write them first, then implement)
1. `domain::job`: `JobId` (`job_`+32 lowercase hex, 128-bit OS random via a port), `JobKind` (closed: `TestNextest` now; `Coverage`, `SemverCheck`, `MutationTest` variants may be declared but must not be constructible into a runnable job until their packages land — prefer adding them later), `JobState`, `JobPhase`, `JobBudget`/deadline types with units, `JobOwnerBinding` (opaque 32-byte digest per ADR-060/061 — computed by the adapter/registry, not by domain), `JobCompletion`, `ExecutionMode {Auto, Task, Synchronous}`, retention quotas. Serde/Schemars where wire-visible; invariants tested.
2. `application::job`: `JobExecutor` with `submit/status/cancel/update/shutdown_and_join`; ports: `JobRegistry` (in-memory impl provided in application tests or a small default impl), `JobClock` (monotonic), `JobSignal` (cancellation intent + observed-cleanup), `JobIds`. Enforce: one active job = the ADR-030 worker permit (expose an adapter hook so the MCP layer composes it with `Workers`); poll/cancel never take the permit; `Cancelled` only after observed cleanup; non-delivery orphan rule keyed on a `DeliveryTracker` port; retention quotas 64/owner–256/server entries and 32/128 MiB bytes (proposals as constants with units); fixed task record TTL 7,200,000 ms; masking of unknown/foreign/expired/revoked ids (same error variant).
3. `application::nextest`: `NextestOptions` (reuse the closed selection grammar of `CheckOptions`/`TestOptions`: package, features, all_features, no_default_features, target, test_filter with the ADR-037 grammar, timeout seconds within a closed range: propose default 300 s / max 3,600 s for the job execute phase per ADR-060, plus `profile` fixed to the product-owned profile), `ProjectNextestPort::run(&self, source: SourceBundle-owned, options, control) -> Result<NextestObservation, ...>` mirroring `ProjectTestPort` in `crates/application/src/test_run.rs`; `NextestObservation` carries typed counts {selected, passed, failed, ignored/skipped, retried/flaky, leaked, timed_out}, per-test rows bounded (max N rows, with omission flag), runtime identity, execution fingerprint, exit status, and raw artifact byte streams handed as `ArtifactStreams` (JUnit XML bytes + stdout/stderr logs) for publication — publication itself goes through the artifact ports (Terra's `crates/application/src/quality_artifact.rs` when it lands; until then keep the M1 `ArtifactStore` path for logs per ADR-061 Stage 0).
4. MCP: DTO `rust.test.nextest` input {project_ref, package?, features?, all_features?, no_default_features?, target?, test_filter?, timeout_seconds?, execution_mode?}; output: envelope like `rust.test` (status, validation_complete, counts, per-test rows bounded, artifacts/resources list, runtime evidence, omission flags, completeness). Keep 512 KiB budget with explicit omissions.
