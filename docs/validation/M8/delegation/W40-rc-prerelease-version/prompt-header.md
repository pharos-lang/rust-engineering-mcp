# W40 — RC1 `v0.9.0-rc.1`: versión de workspace pre-release y cadena de release que admite tags `-rc.N`

Modelo solicitado: Claude Sonnet 5 (`claude -p --model sonnet --effort high`). Rol: worker de release/scripts. Orquestador: Claude Fable 5.1. Sin subagentes. **Nunca en segundo plano: Bash acepta `timeout` hasta 600000 ms; `run_in_background` está PROHIBIDO.** No commit, no push, no tag, no `gh`, no Docker, sin red. **Archivos permitidos:** `Cargo.toml` (solo `[workspace.package] version`), `Cargo.lock` (solo las entradas de los 8 crates del workspace, vía `cargo update --workspace --offline` o edición mínima), `.github/workflows/release-candidate.yml` (solo el job `validate-ref` y el mensaje de error), `scripts/release-artifact.py`, `scripts/release-smoke.py`, `scripts/test-release-artifact.py`, `scripts/test-release-smoke.py`, `CHANGELOG.md`, `README.md`, `docs/compatibility.md`, `docs/publication.md`, `docs/adr/ADR-090-offline-verification-and-incident-response.md`, `docs/adr/ADR-047-publication-license-and-delivery.md` (solo una nota de enmienda datada), `docs/ci.md` (solo si cita el formato del tag). No toques `crates/`, snapshots, `docs/validation/M8/freeze-0.8.0.json` (el freeze 0.8.0 sigue vigente en toda la serie 0.9: plan M8 §1, ADR-086) ni otros scripts.

Contexto y decisión del orquestador (owner: «tras el merge, crear el tag `v0.9.0-rc.1`» y seguir `release-candidate.yml`): el job `validate-ref` exige `^v[0-9]+\.[0-9]+\.[0-9]+$` y el paso «Verify tag matches every workspace package» exige que `cargo metadata` devuelva exactamente el tag sin `v`; `scripts/release-artifact.py:46` y `scripts/release-smoke.py:33` (`TAG`) rechazan también cualquier sufijo («stable semantic version of the form vX.Y.Z»). Con la versión `0.8.0` y ese regex, RC1 fallaría en el primer job. Decisión: RC1/RC2 son **pre-releases SemVer 2.0 `-rc.N`** (tags `v0.9.0-rc.1`, `v0.9.0-rc.2`); la versión de workspace pasa a `0.9.0-rc.1` (Cargo admite pre-release; `CARGO_PKG_VERSION` = `0.9.0-rc.1`; `version --json` la devuelve tal cual) y la cadena de release admite `^v(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)(-rc\.(0|[1-9][0-9]*))?$` — **solo** `-rc.N`, ningún otro pre-release ni build metadata. El paso tag == versión del workspace se mantiene **estricto** (`0.9.0-rc.1` == `0.9.0-rc.1`), sin recortar sufijos. Mantén todo lo demás del workflow intacto (pins, permisos, digests cruzados, `--draft --prerelease`).

Comprueba `cargo metadata --locked --offline --no-deps --format-version 1 | python3 -c 'import json,sys;print({p["version"] for p in json.load(sys.stdin)["packages"]})'` → `{'0.9.0-rc.1'}`.
