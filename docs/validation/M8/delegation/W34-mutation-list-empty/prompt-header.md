# W34 — `mutation list --state-root <nunca usado>` debe listar vacío, no `blocked/io` (tercero F-2)

Modelo solicitado: Claude Sonnet 5 (`claude -p --model sonnet --effort high`). Rol: worker de implementación (Rust). Orquestador: Claude Fable 5.1. Sin subagentes. **Nunca en segundo plano: Bash acepta `timeout` hasta 600000 ms; `run_in_background` está PROHIBIDO.** No commit. No Docker. **Archivos permitidos:** el módulo de la CLI `mutation list/prune` en `crates/mcp-server/src/` (localízalo: `grep -rn '"mutation"' crates/mcp-server/src/main.rs`), `crates/project-adapter/src/filesystem/macos/mutation.rs` solo si el store necesita distinguir «no inicializado», `crates/mcp-server/tests/cli.rs` (test nuevo), `docs/tools.md` (frase de `mutation list`).

Hallazgo del tercero (`docs/validation/M8/06-reproduction.md` F-2): `target/release/rust-engineering-mcp mutation list --state-root <dir vacío que nunca tuvo actividad> --json` devuelve `status: "blocked"`, `error_code: "io"`, mensaje de recuperación de interrupción, exit 1 — reproducido en dos directorios; mientras `doctor --state-root <mismo tipo>` reporta `pending: 0, terminal: 0, unknown_format: 0`. Diagnostica la diferencia (probablemente `doctor` crea el store/lock y `mutation list` intenta abrir un directorio de journals inexistente y mapea `NotFound` a `io`). Decisión del orquestador: **un store nunca inicializado se lista como vacío** (`status: passed`, `records: []`, `count: 0`, con `store_initialized: false` informativo), sin crear archivos si es posible (si `open` exige crear el lock, acéptalo y documéntalo, coherente con ADR-088 §3 y con `doctor`); un directorio inexistente sigue siendo error (`not_found`/`io`) con mensaje claro. Mantén el comportamiento sobre stores con journals. Tests en `cli.rs`: dir vacío → exit 0 y `count 0`; dir inexistente → error; dir con permisos que impiden leer → `io`. Verificación: `cargo fmt --all -- --check`; `cargo clippy -p rust-engineering-mcp -p rust-engineering-project --all-targets --locked --offline -- -D warnings`; `cargo test -p rust-engineering-mcp --locked --offline --test cli --test doctor`; `git status --short crates/mcp-server/tests/snapshots` (sin cambios nuevos). Informe en `docs/validation/M8/delegation/W34-mutation-list-empty/report.md` y en tu última respuesta. No commit.
