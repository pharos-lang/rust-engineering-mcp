## Evidence and limits

Real384-dimensional E5 vectors pass finite/L2 checks; Spanish borrowing query
retrieves ownership first, English JSON query retrieves serde_json first. Queries,
LanceDB table creation/rebuild and SQLite fact rehydration run under macOS
`sandbox-exec` network deny, with IPv4/IPv6 bind positive controls outside and EPERM
inside. A nonexistent TMPDIR remains absent. This is not a full strict sandbox or
an assertion that every socket syscall is denied.

Tests discriminate mismatch before inference, absent/corrupt providers/indexes,
NaN/norm/dimension/duplicate/unknown IDs, payload budgets, freshness, namespace
isolation,1000 rows/1024 dimensions, atomic rebuild failure and bounded results.
A same-size model-file mutation fails hashing before native parsing. The corruption
test deliberately clones487MB; the production loader does not make that copy.

The complete model bytes and native allocator still require substantial memory;
this API does not enforce OS RAM/CPU deadlines. M1 must integrate bounded workers,
MCP tools, authenticated model/native distribution, durable index import and
quality/performance gates. Memory index metadata is bound to its owned table, not
an untrusted persisted manifest. Local model provenance means local verification;
unknown publication age remains unknown, while the receipt records prior download.

Incremental compilation twice exposed stale local metadata during foundation
changes. Non-incremental checks passed; final gates pin CARGO_INCREMENTAL=0 instead
of attributing a compiler root cause without a minimized reproduction.
