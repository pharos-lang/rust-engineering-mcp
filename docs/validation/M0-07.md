# Evidencia M0-07 — Contratos MCP

Fecha: 2026-09-03. Base main b6d6eed, rama ai/m0-07-mcp-contracts.
Rust/Cargo 1.98.1, macOS 26.6.2/APFS ARM64.

La frontera `Contract<I,O>` se usa en project.open: schema generado y cerrado,
validación runtime, Serde con invariantes adicionales y mapping centralizado de
ToolStatus a isError. rmcp 3.2.0 construye structuredContent y su espejo textual.
InvalidParams e InternalError tienen mensajes fijos y no reflejan el payload.
El snapshot existente de la tool es idéntico; no se publican las otras doce tools.

Pruebas nuevas discriminan entradas desconocidas/nulas/tipo incorrecto/largas y
texto vacío según schema, además de whitespace rechazado por el newtype Rust aun
cuando el schema de strings lo admite. Salidas incompatibles no cruzan el borde.
Todos los nueve códigos operativos y cancelación usan structured errors con espejo
idéntico; suprimir cada campo requerido invalida el schema. Un resultado failed del
dominio se adapta a un DTO representativo y conserva isError=false. La tool actual
no compila y no produce failed; el test del DTO no anuncia otra tool implementada.

La suite de protocolo lanza el binario real, verifica snapshot, argumentos inválidos,
status/structuredContent/text y recuperación del servicio en discovery moderno y
cuatro versiones legacy. Tests de dominio cubren invariantes de envelope,
diagnósticos y snapshot evidence; schemas específicos de futuras tools se añadirán
con sus verticales. No se introduce protocolo JSON-RPC propio ni dependencia nueva.

Gate ejecutado:

```text
cargo fmt --check
cargo check --workspace --all-targets --locked --offline
cargo clippy --workspace --all-targets --locked --offline -- -D warnings

cargo test -p rust-engineering-domain --doc --locked --offline
```

conservada, sin presentarla como una calibración nueva. Cargo audit conserva el grafo
