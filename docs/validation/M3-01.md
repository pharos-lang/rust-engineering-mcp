does not enable MCP Tasks; capability advertisement remains gated until M3-02.

## Integrated result

- The approved guest identity is
  `sha256:384a1742ecc53cdd3a9c0bf36c6f8b66db73ddd118aeeae6e55654ea998ae36a`;
  provisioning passed 47/47 observations in `M3-provisioning.json`.
- `rust.test.nextest` is registered with its closed snapshot and preserves the
  structured/text mirror in all five negotiated protocol versions. The checkout
  currently discovers 20 ordered tools because the concurrently integrated
  coverage vertical follows nextest; the first 19 snapshots, including nextest,

- `execution_mode=auto|synchronous` is synchronously qualified only for the
  default profile with `timeout_seconds <= 60`. An unqualified `auto` request
  returns the structured `TASKS_REQUIRED` remediation; explicit `task` remains

  execute default and 3600-second maximum without changing the M1 60-second cap.
- The D06 executor now preserves completed work across cleanup, never applies the
  work deadline to `Cleanup`, joins cleanup independently of cancellation, holds
  the sole ADR-030 permit until observed cleanup, bounds task controls, masks task
  identifiers, and bounds the serialized completion to 512 KiB.
- Nextest config is injected at the product-owned fixed path
  `/source/.rust-mcp-nextest/nextest.toml`. A guardian keeps the Docker-managed
  output volume alive while the run uses it. JUnit egress uses a separate fixed
  `/usr/bin/tar` exporter from `/junit/rust-mcp/reports/junit.xml`; the decoder
  accepts only that regular member and rejects links, extra members, extensions,
  and oversized data. `docker cp` is not used.
- With a qualified state root, JUnit/stdout/stderr publish through the ADR-061
  durable store and are read through owner-bound
  `rust-quality-artifact://` index/chunk Resources. With no state root, or an
  `UnsupportedStateRoot`/`Busy` attach, publication falls back to the unchanged
  ephemeral M1 `ArtifactStore`. Read-time expiry becomes Resource not found and
  task projection `Unavailable` without rewriting the historical job outcome.
- The dedicated quality seccomp profile adds only
  `socketpair(AF_UNIX, SOCK_STREAM|creation flags, 0)` as documented by ADR-064.
  M1 and M2 profile bytes are unchanged. AF_INET, AF_INET6, connect and pathname
  Unix bind controls remain denied, and Docker network mode remains `none`.

## Runtime calibration

Observed against `cargo-nextest 0.9.143` in the approved image:

| Case | Observed process outcome | Structured evidence |
| --- | --- | --- |
| Passing | exit 0 | complete JUnit and passing counts |
| Failing | exit 100 | test failure and failing counts |
| Build error | exit 101 | runner/build failure |
| Slow test timeout | exit 100 | timed-out testcase in JUnit; not exit 104 |
| Active gateway cancellation | no process exit code | cancellation plus observed child and joined cleanup |
| No tests | exit 4 | complete zero-test JUnit; zero counts |
| Flaky, retries=1 | exit 0 | attempts/retries/flaky derived from JUnit |
| Leaky | exit 100 | self-closing JUnit `error` type reports leaked handles |

Q01 repeated all 19 exact nextest selections and reconfirmed this table. Exit 104
was not emitted by any real timeout/cancellation path and remains deliberately
`Uncalibrated`; it is not used to classify either outcome. Hostile stdout markers never become facts;
only bounded JUnit does. The hostile output and JUnit-symlink cases fail closed,
source bytes remain immutable, EOF/cancellation remove all owned Docker objects,
and a second job can reuse the gateway.

The sync timing oracle recorded five cold and five warm passing-fixture samples
inside the final exact gate:

- cold: 1637, 1651, 1621, 1635, 1624 ms (mean 1633.6 ms);
- warm: 1638, 1611, 1645, 1649, 1651 ms (mean 1638.8 ms).

These 10 observations support only the M3-01 bounded rule; M3-02 still owns the
30/30 task-series qualification.

## Limits

30/30 timing series are not claimed here. ADR-064 remains Proposed pending the
orchestrator's containment acceptance even though its authorized implementation
and runtime controls pass.
