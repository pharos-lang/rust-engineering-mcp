# M1-01 — Captured project inspection

## Scope

First M1 vertical: rust.project.inspect with a closed ProjectRef input. Adds the
second tool; the remaining eleven M1 tools are not advertised. No M2 work.
M0 gateway/source/runtime prerequisites are integrated and remain distinct from
this application/MCP composition. Branch ai/m1-01-project-inspect starts from
clean main9d189c9 in an isolated local worktree; no remote operations.

## Implementation

Domain typed declarations and additive ProjectSnapshot source kind. Application
owns no-touch source capture, inspection port, evidence assessment and final live
reference revalidation; invalidation/TTL/cancellation cannot publish a snapshot.
Runtime adapter composes the explicit approved image, active calibration, frozen
metadata and bounded typed parser. Metadata IDs become local indexes; paths stay
relative, dependency URLs are represented by fingerprints. Declared profiles and
features are not effective resolution. See ADR-032 for limits and assumptions.

MCP joins real blocking workers; permit/panic latch follow actual completion.
EOF and I/O failure cancel workers; shutdown checks joined completion/quarantine
with explicit Rust240s grace. Costly bootstrap request is denied before execution.
Failed calibration is latched (except clean cancellation) and cannot repeatedly
execute containment scenarios at peer request. No runtime downloads or installs.
