  ownership/modes. ACL grants remain a trusted host provisioning prerequisite;

  trust-channel, invalid-floor and unverifiable-active errors; real key rotation
  keeps the old floor and accepts a higher sequence under the new key.
- HTTPS exact host/443, webpki roots, no proxies/redirects/retries/decompression,
  streamed80MiB and deadlines. Loopback TLS tests exercise actual transport; no
  official endpoint or publisher identity is invented.
- Native persistence exports actual Lance8 objects; restore uses only memory stores,
  validates object hashes/schema/rows/model/catalog and exact crate-name membership.
  Rebuild and signed embedded-index import use real verified E5/ORT. Corrupt signed
  native payload fails before floor/activation. There is no synthetic-vector claim.
