# M1-02 — Installed toolchain inspection

## Scope and implementation

Branch ai/m1-02-toolchain starts from clean maina726d18 after M1-01 runtime smoke.
Adds the third public tool. ADR-033 specifies project_ref, live revalidation,
installed inventory, source/runtime/individual execution fingerprints and snapshot
provenance/freshness/latest_known. No host toolchain discovery or network/install.

Shares one RustProjectInspector and its gateway/calibration/quarantine with
project.inspect. New InstalledComponents enum maps only to fixed cat/path inside
the approved image. The updated command set enters the configuration fingerprint;
actual calibration is repeated for this configuration. Parsed records are exact
observations of the approved immutable runtime; no supported-target substitution.

## Limits

fields are deliberately pinned to the immutable image. The gateway snapshot
belongs to Linux ARM64, not the macOS host. Full semantic gate remains for integral
closure with unchanged explicit assets. No new image, remote action, Resource,
catalog import, native OS/architecture support, license or utility claim.
